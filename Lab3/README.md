# Lab 3 – Descriptive Statistical Analysis (Wine Dataset)

## Aim
To apply descriptive statistical techniques to summarize and interpret the Wine dataset before applying any machine learning models.

---

## Dataset Used
- **Dataset Name:** Wine Dataset
- **Source:** UCI Machine Learning Repository
- **Total Instances:** 178
- **Total Attributes:** 14
- **Target Variable:** Class (Wine cultivar: 1, 2, 3)

---

## Descriptive Statistical Techniques Applied

The following statistical measures were computed to understand the dataset:

### Measures of Central Tendency
- Mean
- Median
- Mode

### Measures of Dispersion
- Standard Deviation
- Variance (via covariance matrix)

### Measures of Spread
- Minimum
- Maximum
- Quartiles (25%, 50%, 75%)
- Percentiles

### Relationship Analysis
- Correlation
- Covariance

---

## Statistical Summary
- The dataset is clean and contains no missing values.
- Wine classes are fairly balanced.
- Several chemical attributes show high variability.
- Some features are skewed and contain outliers.
- Strong correlations exist between certain chemical properties, indicating redundancy.
